Generador de prompts para análisis financiero

Prepara instrucciones más claras para usar en tu asistente de IA habitual. El generador no evalúa activos, no consulta cotizaciones y no envía tus campos a ningún servicio.

Personaliza tu prompt

No pegues aquí información privada, contraseñas, IBAN, claves API ni frases semilla.

Selecciona el tipo de análisis y pulsa “Generar prompt”.

Cómo utilizarlo

  • Abre tu asistente de IA en otra pestaña.
  • Adjunta solo documentos públicos o datos anonimizados.
  • Pega el prompt y aporta las fuentes originales.
  • Verifica las cifras críticas en los documentos.
  • Guarda el resultado como borrador, no como señal de trading.
Privacidad: esta herramienta funciona localmente en el navegador. El texto solo se copia si pulsas el botón; no se transmite mediante esta página.

Una limitación importante

Este generador no se conecta a ChatGPT, Claude, Gemini ni a datos de mercado. Es una plantilla de instrucciones; el asistente que uses puede equivocarse, estar desactualizado o no disponer de las fuentes necesarias.
